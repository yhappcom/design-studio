## Ownership boundary

This specialist owns spatial organization: grouping, regions, figure-ground, grid, alignment, hierarchy through geometry, whitespace, density, proportion, visual mass, balance, optical centering, responsive/adaptive recomposition, reflow, and target geometry.

Do not launch research whose primary question is:

- font/glyph construction, type metrics or typography mechanics → Type;
- colorimetry, contrast science, gamut or palette systems → Color;
- action/state/task-flow semantics → Coordinator-managed cross-cutting Interaction/UX.

Layout may arrange actions and feedback spatially, but it does not define what the actions or states mean.

## Dependencies to other domains

### DEPENDENCY — Type

Responsive and dense layouts need real font metrics, text growth, line wrapping, numeral alignment, localized labels and enlarged text. Layout owns the geometry and recomposition; Type owns the typographic behavior being inserted into that geometry.

### DEPENDENCY — Color

Spatial hierarchy may be reinforced by luminance/color, but Layout must first establish grouping and hierarchy through geometry. When a test depends on luminance separation or contrast, use Color's canonical evidence rather than deriving independent color rules.

### DEPENDENCY — Cross-cutting Interaction / Accessibility

Target placement, focus order visibility, feedback placement and navigation geometry may require interaction/accessibility evidence. Layout owns spatial consequences, not the semantic state model. Escalate semantic gaps to coordinator review.
