## Evidence classification

### CANONICAL PRODUCT / existing project contract
The product must preserve professional record meaning and stable object identity through edit/import/reorder/recovery flows. Existing interaction studies consistently separate candidate, commit, persistence and sync truth.

### NORMATIVE
WCAG 2.2 remains the accessibility baseline. Existing evidence already requires equivalent non-drag single-pointer operation where SC 2.5.7 applies; keyboard access alone does not close that path.

### SUPPORTED DESIGN PRINCIPLE
Visual salience follows **state consequence**, not brand emphasis. Focus, selection, pending, ambiguous, invalid, committed, recoverable and persisted/synced are not interchangeable styling opportunities.

### PROJECT-SPECIFIC CANDIDATE
A recognizable LogMate interaction code may come from unusually consistent transition/recovery behavior: stable geometry, restrained motion, predictable focus return and immediate reversible feedback. This is a candidate identity mechanism, not yet a brand rule.

### OPEN
Whether pilots perceive this consistency as premium, calm, trustworthy or distinctive requires owner/representative-human evidence. Do not infer emotional brand success from deterministic behavior alone.

## Precedence contract
For a proposed visual/interaction code:
1. professional semantic/safety truth wins over stylistic novelty;
2. normative accessibility/platform behavior wins over ornamental consistency;
3. actual consequence/state ownership wins over generic brand salience;
4. reversibility and recovery must remain discoverable;
5. brand expression may shape motion/feedback only inside those constraints.

## Contradiction review

### Brand calm vs necessary state salience — Class D priority tension
A restrained visual system may reduce noise, but destructive, invalid, ambiguous, focus and recovery states still need sufficient differentiation. Resolution: reduce persistent chrome first; do not mute consequence-bearing state.

### Signature motion vs reduced motion / latency truth — Class A if motion carries meaning alone
Resolution: motion may reinforce transition continuity but cannot be the sole state channel. Reduced-motion behavior must preserve semantic result and focus/recovery truth.

### Stable geometry vs responsive adaptation — Class B scope contradiction
Stable comparison axes are mandatory for repeated operational data; whole-screen coordinates are not. Recomposition may change regions while preserving within-region comparison axes and semantic order.

### Direct manipulation vs SC 2.5.7 — unresolved implementation blocker
Drag reorder remains insufficient without an implemented non-drag single-pointer alternative. This blocks promotion of drag itself as a signature interaction.

## Reproducible future validation

Record semantic object ID, state before/after, focus before/after, recovery availability, geometry delta, reduced-motion behavior, 200% behavior and visible/a11y result. Repeat twice per executable runtime family.
