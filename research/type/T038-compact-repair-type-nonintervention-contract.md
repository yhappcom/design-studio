# T038 — Compact Repair Type Non-Intervention Contract

Date: 2026-09-18
Stage: Stage 2 PRACTICE
Purpose: TRANSFER VALIDATION

The current MintTap compact failure remains composition pressure unless independent evidence demonstrates a glyph or metric defect.

## Contract
- Preserve drawing → general spacing → residual kerning.
- Do not reduce tracking, font size, glyph width, or pair spacing merely to make a compact composition fit.
- Layout owns recomposition; Content owns semantic abbreviation decisions.
- After repair, rerun baseline and enlarged-text scenarios, then inspect fallback, line breaks, clipping, vertical metrics, numerals/punctuation, and raster.
- Type intervention requires evidence attributable to glyph, metrics, general spacing, pair residual, fallback, or raster. Composition pressure and semantic truncation remain handoffs.

Human readability/usability evidence remains OPEN.
