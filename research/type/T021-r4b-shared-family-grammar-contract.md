## R4B construction grammar v0.1

All values are provisional design constraints in a 1000 UPM coordinate system, not claims that these are optically correct final values.

### 1. Round control — O / o / 0

- cap height: 700; cap overshoot: ±12;
- x-height: 500; lowercase overshoot: ±10;
- cap round outer width: 470 over 724 total overshoot height, ratio **0.649**;
- lowercase round outer width: 410 over 520, ratio **0.788**;
- cap counter clearance: 90 units on left/right/top/bottom in the invariant model;
- lowercase counter clearance: 80 units on all four sides;
- `0` inherits the cap-round outer grammar but remains a coordinated figure and retains an explicit slash candidate so O/0 distinction is not left to spacing or context.

The important change from R4A is not the numeric symmetry itself. It is that O/o/0 now have one declared reference grammar against which deviations must be explained.

### 2. Bowl / counter tension — D / B / P / R / 8

One bowl policy is declared for the group:
- nominal stem: 82;
- join inset: 18;
- minimum modeled counter dimension: 150;
- waist reference: y=350 for cap/figure transfer.

These are starting constraints. B/P/R/8 are not required to be geometric copies. A deviation is acceptable only when it has a glyph-specific optical/structural reason and survives intended-size raster critique.

### 3. Aperture / terminal family — C / G / S / 5

One aperture/terminal policy is declared:
- minimum opening reference: 105 units;
- terminal-cut reference: 8 degrees;
- S and 5 remain structurally distinct; shared terminal language must not normalize them into an ambiguity collision.

R4A's mistake was to treat curvedness as the common property. R4B instead treats opening, terminal attitude and tension as the transferable property.

### 4. Shoulder — n

The lowercase shoulder gets a declared relation rather than an isolated redraw:
- rise reference: y=380;
- peak reference: y=510, including overshoot space;
- join-x reference: 180.

The n is not forced to imitate a capital bowl. Its job is to reuse curve tension and terminal logic sufficiently to belong to the same family while retaining lowercase rhythm.

### 5. Coordinated figures — 0 / 1 / 5 / 8

- common provisional figure advance: 560;
- 0: slash candidate retained;
- 1: base candidate retained;
- 5: open-top distinction retained;
- 8: upper/lower counter relationship declared together rather than as two unrelated bowls; initial ratio parameter 0.92.

This makes ambiguity control subordinate to a figure system rather than a set of emergency patches.

### Critical evidence boundary

**10/10 is not a drawing PASS.** It proves only that the written grammar is internally consistent and executable as a constraint model. A perfectly consistent bad typeface is still bad. The next gate remains actual outline construction followed by 14/17/24px raster critique.

## Failure conditions defined before drawing

R4B must be rejected or revised before full 36/36 promotion if the prototype shows any of the following:

1. O/o/0 round rhythm still appears compressed or malformed at 17px;
2. B/D/P/R/8 counters do not read as related tensions despite nominal shared constraints;
3. C/G/S/5 terminals appear mechanically identical or cause S/5 ambiguity;
4. n looks imported from a different family or becomes too closed at 14/17px;
5. 0/1/5/8 ambiguity mechanisms dominate the figure texture;
6. the grammar requires kerning to hide drawing or general-sidebearing defects;
7. the shared numeric constraints prevent necessary optical corrections.

## KEEP / REWORK / REJECT

**KEEP:** shared-grammar-first method, explicit group invariants, coordinated figures, kerning OFF, target-size raster as the next gate.

**REWORK:** all numeric values are provisional. They are constraints for the first R4B prototype, not sacred geometry. Raster evidence may justify asymmetric counters, different overshoots, altered apertures or figure widths.

**REJECT:** promoting this model directly into the full candidate or claiming family coherence because the invariant harness passes.
