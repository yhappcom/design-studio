## Synthesis findings
1. Stable operational comparison is a joint Type+Layout responsibility.
2. `tabular-nums` can stabilize digit advances when the selected font supports the feature, but it does not solve mixed alphanumeric flight identifiers, registrations or arbitrary punctuation.
3. Mixed identifiers therefore require explicit column/value geometry and realistic stress strings, not a blanket “use monospaced text” rule.
4. A brand type treatment cannot be promoted if it introduces visible jitter into repeated operational axes.
5. Mature fallback remains the current product-transfer control until T021 drawing and later spacing gates close.

## Contradiction matrix
- **Distinctive custom type vs stable geometry — Class C evidence-level:** custom candidate is provisional; do not let identity work freeze around it.
- **Dense fit vs semantic strings — Class D:** do not condense/tracking-adjust immature drawings or shorten required semantics to force fit.
- **Tabular numerals vs mixed identifiers — Class B:** tabular figures help numeric fields only; mixed identifiers need separate geometry validation.
- **Brand consistency vs fallback resilience — Class D:** identity must degrade coherently when custom font is unavailable; fallback is not an exceptional afterthought.
