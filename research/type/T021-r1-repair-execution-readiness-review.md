2. compensating drawing defects with kerning;
3. changing metrics while claiming a drawing-only comparison;
4. over-strengthening the B zero slash so dense numeric strings gain texture/noise;
5. selecting a winner from 24px while 14/17px remains ambiguous;
6. treating deterministic raster improvement as human recognition evidence.
