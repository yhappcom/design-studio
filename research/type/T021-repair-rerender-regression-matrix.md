# T021 Repair → Rerender Regression Matrix

Status: **PRACTICE / REPAIR EXECUTION GATE**  
Purpose: convert the verified T021 repair locus into a bounded, falsifiable rerender decision rather than another unconstrained drawing iteration.

## RELATED DOMAIN CHECK

- **Type:** direct A/B critique already isolated `I/l/1` ambiguity and candidate-B zero-slash dominance. The executable source locus is known; kerning is OFF and sidebearings are frozen for the first repair.
- **Color:** C042 cannot compensate for glyph ambiguity; proof must remain readable without relying on state color.
- **Layout/Interaction:** L033/I029 require stable operational identifiers and timestamps; provisional metrics must not be frozen into product geometry.
- **Web:** W042 remains on mature fallback until T021 drawing/general-spacing gates close.
- **Content:** CD048 introduces timestamp/revision strings that increase the importance of `I/l/1/0/O` discrimination.
- **UX integration:** human recognition remains OPEN; this matrix is deterministic drawing/raster evidence only.

Analytical purpose: **REPLICATION + REGRESSION VALIDATION**. The next rerender must prove that a local ambiguity repair did not damage the bounded operational family.

## Gate order

`drawing repair → kerning-OFF rerender → direct drawing critique → general spacing → residual pair defects → T022 kerning`

No result in this study authorizes skipping general spacing or opening T022.

## Frozen variables for repair iteration R1

- sidebearings and advance widths: frozen;
- kerning/GPOS pair positioning: absent/off;
- UPM, cap height, x-height and proof sizes: unchanged;
- bounded operational corpus and ambiguity strings: unchanged;
- unrelated glyph outlines: unchanged.

A repair that requires changing these variables is a new iteration and must be identified as such.

## R1 mutation set

Only these constructions may change:

1. uppercase `I` — strengthen primary silhouette distinction without using pair spacing;
2. lowercase `l` — distinguish from `I` and `1` through construction, not a tiny raster-fragile ornament;
3. digit `1` — retain numeral identity while separating its cap/foot logic from `I/l`;
4. candidate-B `0` slash — preserve `O/0` distinction while reducing slash dominance at 14/17px.

Candidate A plain zero is a control unless direct rerender evidence exposes a new defect.

## Required proof matrix

For A and B, render at **14 / 17 / 24 px**:

- ambiguity: `I l 1`, `Il1`, `I1l`, `O0`, `0O`, `10I`, `L1I`, `00O`;
- identifiers: bounded flight/airport/registration-like strings already canonical in T021;
- numeric/time: bounded totals and time strings already canonical in T021;
- spacing controls: existing H/O/n/o and uppercase spacing strings;
- full bounded repertoire coverage and fallback/notdef check.

Every proof bundle records source SHA, build hash, font hash, raster hash, candidate, size and mutation iteration.

## Deterministic acceptance rules

R1 is **REJECT** if any of the following occurs:

- `I/l/1` distinction improves only at 24px but collapses at 14 or 17px;
- distinction depends on kerning or sidebearing changes;
- B `0` slash remains the dominant interior feature in dense numeric strings;
- O/0 distinction becomes weaker than the pre-repair B control without a compensating construction rationale;
- unrelated bounded strings regress through accidental outline/metric mutation;
- missing glyph/notdef/fallback appears;
- repair creates a new general-spacing defect that is then hidden by pair-specific adjustment.

R1 may advance to **general-spacing critique** only when the repaired constructions survive all three sizes and the unchanged-family regression set remains stable.

## Critique ledger schema

`candidate | iteration | glyph/string | size | defect class | pre-repair observation | post-repair observation | regression? | next action | evidence hash`

Defect classes remain: `drawing`, `general-spacing`, `pair-specific`, `fallback/notdef`, `renderer-transfer`, `human-evidence-open`.

## Evidence boundary

This matrix does not claim repaired raster evidence, drawing PASS, spacing PASS, custom-font production readiness, browser/native transfer or human recognition. It removes ambiguity about what the next executable repair must prove.

- **Layout/Web:** do not lock dimensions to repaired metrics until general-spacing acceptance.
- **Color:** test state cues independently; color must never be used as a character-disambiguation aid.
