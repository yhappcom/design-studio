# T090 — Pre-runtime saturation and gate stop rule

Evidence class: **CONTRADICTION REVIEW / STUDIO JUDGMENT**

## Purpose
T089 already defines the executable Candidate 05/07 type stress fixture. This audit asks whether more pre-runtime typography documents can materially reduce uncertainty before T021 drawing or exact runtime evidence exists.

## RELATED DOMAIN CHECK
- Color C120, Interaction I107, Layout L111, Web W120 and Content CD126 already define the shared executable stress packet.
- No peer evidence changes the Type gate order: drawing precedes general spacing; residual kerning follows spacing.

## Finding
Pre-runtime transfer specification is saturated for the current Home candidates. Additional string-fit or candidate-specific typography notes would mostly restate T089 and risk treating documentation volume as evidence.

The remaining high-value Type uncertainties are empirical:
1. T021 bounded drawing quality in a complete-source environment;
2. general-spacing behavior after drawing PASS;
3. actual resolved font/fallback and TextScaler behavior in exact Candidate 05/07 runtimes.

## Stop rule
Do **not** open another Candidate 05/07 type-transfer note unless at least one of these changes: exact source/runtime becomes executable; a new material string/representation class appears; a reproducible contradiction is observed; or T021 advances a gate.

Do not repair immature drawing with tracking, narrowing, semantic shortening or kerning.

## HANDOFFS TO OTHER SPECIALISTS
Layout and Content should treat type-fit pressure without asking Type to violate the drawing→spacing→kerning sequence. Web should capture resolved-font evidence when runtime becomes executable.
