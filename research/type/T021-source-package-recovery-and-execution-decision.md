## Decision
The T021 evidence chain is now specification-complete enough that further conceptual Type notes have sharply diminishing value. The unresolved prerequisite is artifact recovery: a canonical editable glyph source plus deterministic build/proof commands. The repository evidence reviewed in this cycle establishes neither.

The next Type action therefore has two branches and must not silently switch between them:

### Branch A — source recovered
Record source path, blob/version identity, units-per-em and vertical metrics; execute the deterministic build; render H/O/n/o/l/I/1/0 at 14/17/24px with kerning OFF; classify every defect drawing → general spacing → raster → fallback/notdef → pair residual; repair only the first four within T021; rerun before expanding the corpus.

### Branch B — source not recovered
Do **not** recreate a new font from screenshots/raster proofs and call it continuation of the candidate. Treat reconstruction as a new candidate requiring explicit provenance and baseline revalidation. Keep mature product/system fonts as transfer baseline and keep T022 closed.

## Acceptance package
A claimed T021 drawing advance requires, in one evidence bundle:
1. editable-source identity/hash;
2. build command and generated font identity/hash;
3. proof command with kerning disabled;
4. 14/17/24px before/after artifacts;
5. bounded fallback/notdef report;
6. defect ledger with primary failure class;
7. explicit statement that no kerning repaired a drawing/general-spacing defect.

## UX / product consequence
This is not merely font-production hygiene. In a professional resumption/retrieval workflow, identifiers may carry operational identity. Until the ambiguity controls are executable and validated, Web/Layout must not reduce spacing or freeze widths around the incomplete candidate, and Content must not abbreviate identifiers to compensate.

## HANDOFFS TO OTHER SPECIALISTS
Web/Layout retain mature font metrics. Content/Interaction retain full semantic identifiers. Color reports glyph ambiguity back to Type. UX integration treats identifier recognition as human evidence OPEN until product-stage observation.
