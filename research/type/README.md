# Typography & Type Design Research

This directory is the canonical research home for the **Typography / Type Design Specialist**.

## Primary scope

Research belongs here when its primary question concerns:

- type anatomy, construction, stroke logic, curves, and optical correction;
- metrics, spacing, kerning, rhythm, and raster behavior;
- numeral and punctuation systems;
- family planning, variable fonts, OpenType, multiscript/fallback behavior;
- typography as information architecture and semantic text-role systems;
- type production, rendering, licensing, and font engineering.

## Boundary with other disciplines

- **Layout & Spatial Design** owns screen-level spatial composition, grids, alignment, grouping, density, and responsive recomposition. Typography research may inform those decisions but does not own the overall screen geometry.
- **Color** owns colorimetry, color perception, gamut, contrast/color systems, and color-management questions.
- **Interaction** owns actions, navigation, state, feedback, modes, recovery, temporal behavior, and interaction semantics.

When a study crosses these boundaries, keep one canonical owner and link to the related research rather than duplicating the same knowledge in multiple files.

## Before using type knowledge in another domain

1. Check `progress/STATUS.md` for the current evidence level and unresolved gaps.
2. Read this README and the relevant studies below.
3. Distinguish established evidence from studio judgment and OPEN items.
4. Do not treat a Type finding as a universal Layout, Color, or Interaction rule without transfer evidence.
