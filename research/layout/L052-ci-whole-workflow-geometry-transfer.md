# L052 — CI Whole-Workflow Geometry Transfer

Evidence purpose: **TRANSFER VALIDATION**

## RELATED DOMAIN CHECK
W061 supplies the executable manifest; T030 supplies real string/rendering pressure; C061 supplies semantic state redundancy; I048 owns temporal continuity; CD067 owns semantic continuity.

## Objective
Make the first CI run test product geometry as a workflow system, not a screenshot collection.

## Protected groups
Across Start → Portfolio → Holding → Add → Insights/ROC/Tax → Settings preserve:
- label → value → qualifier;
- field → error → correction;
- state → action → recovery;
- primary first-value task before promotional/ad interruption.

## Scenario geometry
Record at least narrow-phone and wide/tablet conditions, baseline and enlarged-text diagnostic, long localized strings, KRW/USD, contradiction states and partial/unavailable states. Current compact-iOS cap behavior and unclamped diagnostic behavior are separate evidence conditions.

## Failure conditions
- clipping or hidden truth-bearing content;
- semantic detachment after reflow;
- avoidable two-dimensional scrolling for ordinary reading/task content;
- focus or primary action obscured by sticky/overlay UI;
- target geometry below the product/platform acceptance contract;
- promotional/ad placement interrupting first value;
- a layout revision that fixes one scenario by breaking another protected group.

## Critique rule
A CI screenshot can prove rendered geometry for its exact identity; it cannot prove discoverability, workload, preference or representative usability. Those remain human evidence.

## Next block
Run the same W061 manifest through all protected groups and produce a failure ledger by scenario. Revise systems, not isolated pixels.

## HANDOFFS
Type receives genuine metric/rendering failures only; Color receives adjacency/context failures affecting state encoding; Interaction receives focus/action continuity failures; Content receives truncation/semantic ordering failures; Web owns runtime reproduction.

## Evidence boundary
No Stage 3 PASS, physical-device, AT or representative-human usability PASS is claimed.
