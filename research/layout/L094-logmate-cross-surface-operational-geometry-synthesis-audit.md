## Evidence synthesis

### Supported spatial invariant
Repeated operational data needs stable comparison axes. Date, flight identifier, DEP/ARR, registration and duration families should not visibly jitter merely because glyph widths differ. This is a geometry requirement before it is a visual-style preference.

### Important limitation
Stable axes do **not** imply a universal fixed grid across Home, Activity, Add Flight and View Logbook. Cross-surface identity should preserve relationship logic, not identical coordinates.

### Candidate reusable spatial code
A LogMate-specific visual code could emerge from disciplined alignment of operational values, predictable region ownership and low-chrome containment. This remains a PROJECT-SPECIFIC CANDIDATE until multi-surface visual/runtime evidence exists.

## Contradiction matrix
- **Density vs semantic-string protection — Class D:** preserve full meaning; solve with hierarchy, wrapping/recomposition or progressive disclosure before truncating required semantics.
- **Stable data axes vs responsive reflow — Class B:** ledger comparison axes may remain stable inside a scroll/recomposed region while surrounding page layout changes.
- **Minimal chrome vs discoverability — Class D:** boundaries may be visually quiet only if grouping, target geometry and state remain unambiguous.
- **Brand repetition vs surface fitness — Class B:** a repeated spatial code must transfer by rule, not by copying Home composition into dense ledger/forms.
- **Custom-font metrics vs geometry — Class C:** provisional T021 metrics cannot be used to certify stable axes; mature fallback is the current control.

## Accessibility constraints
WCAG 2.2 remains the baseline. Reflow must preserve information/function at the criterion's required conditions except content genuinely requiring two-dimensional layout for usage/meaning. Text-spacing overrides must not cause loss of content/function. Meaningful UI boundaries/state cues require non-text contrast where applicable. These are constraints on any future design corridor, not evidence that a particular layout is usable by humans.
