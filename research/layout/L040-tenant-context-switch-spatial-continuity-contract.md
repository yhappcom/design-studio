# L040 Tenant Context Switch Spatial Continuity Contract

Evidence mode: **STAGE 3 SYSTEMS PRACTICE / TRANSFER VALIDATION**.

## Goal
Preserve context identity and safe action hierarchy while tenant/workspace content is replaced, invalidated or temporarily uncertain.

## RELATED DOMAIN CHECK
I036 supplies authority/action truth; C049 supplies cue precedence; W049 supplies route/cache runtime evidence; CD055 supplies labels/status language; Type remains provisional.

## Information spine
Maintain, in reading and focus order:
`current context → context certainty/change → object identity/consequence → available safe action/recheck → history/provenance`.

A persistent sidebar/header must not visually claim B while the main region still presents actionable A content without stale-state qualification. Conversely, hiding all A content is not mandatory if product policy permits safe read-only retention; retained content must remain subordinate to context uncertainty.

## Stress matrix
- 320 CSS px and wide desktop;
- 200% text and long localized context names;
- context selector wraps to two lines;
- focused action removed on switch;
- same object ID in A/B;
- stale A table rows while B shell loads;
- rapid A→B→A response reorder;
- history/deep-link restoration;
- print/export.

## Acceptance
No overlap, clipping or offscreen current-context indicator; logical focus destination after control removal; stale region cannot visually dominate confirmed B authority; responsive reordering cannot separate context qualifier from the object/action it governs.

## Evidence boundary
No executed geometry, AT, physical-device or human scanning/workload PASS is claimed.

## HANDOFFS TO OTHER SPECIALISTS
W049 must capture bounding boxes/focus order under transition; C049 validates cue survival; CD055 provides long/pseudo-localized strings; Type metrics remain non-binding until T021 drawing/spacing gates close.
