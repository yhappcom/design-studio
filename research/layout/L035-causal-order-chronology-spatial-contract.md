# L035 — Causal Order / Chronology Spatial Contract

## PURPOSE

Extend L034 where visible chronological order and causal/authoritative order diverge.

## SPATIAL CONTRACT

A history surface may sort by a user-facing time, but it must not spatially imply that row position alone equals authority. Where causal order differs, keep these locally associated: event identity → displayed time role/value → causal/order indicator → authoritative consequence → safe action/history detail.

If the product exposes both event chronology and reconciliation/authority sequence, their labels and ordering basis must remain discoverable under narrow width, 200% zoom, long localization, page breaks, and print/export.

## FAILURE CONDITIONS

- reflow separates an order indicator from the event it qualifies;
- page break makes a causally older event look like the current consequence;
- sorting control says “latest” without defining the basis;
- long zone labels push authority/sequence evidence out of the visible action context;
- focus/selection position is mistaken for current authority.

## RELATED DOMAIN CHECK

Type: provisional T021 metrics cannot define final fit. Color: C044 supplies non-recency visual precedence. Interaction: I031 owns causal truth/action safety. Web: W044 supplies runtime geometry/order evidence. Content: CD050 supplies sorting/order labels and uncertainty language.

## HANDOFFS TO OTHER SPECIALISTS

## EVIDENCE BOUNDARY

Spatial systems contract only; no executed browser/print geometry, AT reading-order, physical-device, or human scanning/workload PASS.
