# L026 — Partial-Authority Action Proximity

Date: 2026-09-16
Evidence class: **SYSTEMS PRACTICE / SPATIAL CRITIQUE / BROWSER TRANSFER OPEN**

## RELATED DOMAIN CHECK
I022 defines which facts are known/unknown; CD041 names them; C035 checks cue survival; W035 supplies responsive/runtime geometry; Type T021 metrics remain unavailable.

## Spatial invariant
When an action depends on uncertain authority evidence, the uncertainty and the affected object/action must remain perceptually associated under baseline, narrow reflow, actual zoom and localized expansion. A global banner alone is insufficient when it is ambiguous which action is constrained.

## Priority model
1. object identity;
2. action-relevant authority/freshness state;
3. missing or conflicting fact and consequence;
4. safe available action or reconciliation control;
5. history/detail evidence;
6. secondary metadata.

## Geometry record
For each shared run ID capture object rect, state/certainty rect, affected action rect, reconciliation rect, sticky/overlay rect, focused rect, viewport and visualViewport. Record reordering, separation, clipping, overlap and horizontal overflow independently.

## Critique
- Association failure is not repaired by stronger color.
- Reflow that moves the uncertainty away from the affected action is a semantic-spatial failure even if all text remains visible.
- Entire focus obscuration is evaluated against WCAG 2.2 SC 2.4.11; stronger studio visibility goals are recorded separately.
- 320 CSS px reflow is not labeled actual 200% browser zoom.

## Evidence boundary
No browser/layout PASS until executed geometry exists. Human noticeability and cognitive load remain OPEN.

## HANDOFFS TO OTHER SPECIALISTS
W035 captures geometry; C035 consumes focus/overlay state; CD041 must avoid text that assumes proximity the layout cannot preserve; I022 remains authority for action safety.
