## Invariant geometry contract
Across phone, tablet/EFB and desktop/web, runtime transfer fails if recomposition changes any of:
1. record identity availability;
2. state/certainty adjacency to the affected record;
3. safe-action availability implied by I008;
4. meaningful source/reading/focus order;
5. recovery-context visibility after interruption;
6. access to required literal identifiers under localization expansion.

The following may adapt: column count, list/detail simultaneity, disclosure depth, navigation chrome, whitespace and density.

## Stress matrix
| stress | spatial assertion | failure condition |
|---|---|---|
| narrow phone | sequential task remains complete | action/state detached or hidden |
| tablet/EFB | master/detail preserves selection context | detail replaces identity/certainty context |
| desktop | density may increase | visual order contradicts task/focus order |
| 200% text/zoom | recompose before semantic clipping | two-dimensional task scrolling or lost action |
| +40% pseudo expansion | containers grow/reflow | qualifier/recovery text truncated |
| RTL wrapper | regions mirror only where appropriate | operational LTR literals fragment/reorder |
| sticky/transient UI | focus target remains perceivable | focused target fully obscured |
| state transition | layout may update | certainty/safe action changes due to viewport rather than state |

## T022 numeric-layout handoff
Do not force airport/identifier strings to equal widths. Comparison-critical time/total columns may use stable column geometry and, if exact product-font/native evidence supports it, tabular figures. Font feature support alone does not authorize narrower cells: 200% text, locale formatting and fallback remain layout stressors.

## Acceptance boundary
This matrix is deterministic expert/system evidence. W021 browser execution can provide Web transfer evidence and contradictions; native Flutter must be validated separately. Human workload, scan efficiency and recognition remain OPEN.
