Date: 2026-09-19
Stage: Stage 3 PRACTICE
Evidence purpose: TRANSFER VALIDATION + SYSTEM INTEGRATION

## RELATED DOMAIN CHECK
I087 owns consequence/reversibility truth; L091 owns review/action geometry; C100 owns state encoding; T069 owns rendering; W100 owns browser/runtime evidence. Content names the actual object, consequence and recovery without inventing certainty.

## SOURCE / SYNTHESIS
WCAG 2.2 SC 3.3.4 requires reversible, checked, or confirmed protection for covered legal/financial/data-changing submissions; SC 3.3.6 applies the same alternatives to all information submissions at AAA. This does not mandate a confirmation dialog for every action. Content should follow the selected product contract.

## CONTENT CONTRACT
`intent label ≠ consequence description ≠ confirmation ≠ commit result ≠ recovery availability ≠ recovery result ≠ Saved/Synced`.

For material actions, preserve `object → consequence → available recovery`. Prefer specific action labels when consequence matters; avoid generic “OK” where the decision is destructive or scope-sensitive. A review surface must describe the same semantic payload that will be committed. Undo language is allowed only while a truthful inverse remains available.

## COMPLETE-SYSTEM PRACTICE
Carry forms/state/onboarding/retrieval/tone/localization through: reversible preference change; delete one flight record; replace an import batch; Reset customized fields; invalid multi-field edit; review-before-commit; cancel; Undo success/failure; Back/Forward return. Maintain stable object IDs and typed variables. English source remains primary; Korean is transfer stress, not a production localization PASS.

## CRITIQUE / FAILURE CONDITIONS
FAIL if “Save” is used for a local mutation with no persistence truth; “Undo” is offered after inverse expiry; generic confirmation hides scope; success wording appears before commit; failed recovery says restored; warning wording invents irreversibility; or strings are shortened until object/consequence/recovery distinctions disappear.

## REPRODUCIBLE VALIDATION
Compare concise visible feedback with richer accessibility payload at baseline/200%, forced colors and independent engine. Human comprehension, trust, interruption cost, linguistic review, AT comprehension and representative-pilot task evidence remain OPEN.
