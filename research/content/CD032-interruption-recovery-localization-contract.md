# CD032 — Interruption, Recovery and Localization Content Contract

Evidence type: SYNTHESIS / PRACTICE / DEPENDENCY / OPEN

## RELATED DOMAIN CHECK
I013 is authoritative for interruption/outcome truth. W025 defines the true-origin runtime transfer. L018 protects long strings and recovery geometry. C027 prevents color-only state dependence. T022 must accommodate required strings later rather than shortening semantics to fit immature drawing.

## Complete-state content model
Each recoverable state needs independently addressable fields rather than one free-form message: `state_title`, `what_happened`, `record_identity`, `certainty`, `safe_next_action`, optional `secondary_action`, and optional `persistence/reconnect_note`. Message IDs must remain stable across wording revision; semantic revision should be traceable separately.

## Conditional-copy correction
`Keep this screen open` is permitted only if leaving/refreshing materially changes recoverability and the product can support that claim. `Fix the connection` is permitted only for a connection-classified failure. Outcome-unknown must not say `failed`; known failure must not imply possible completion; offline/stale must identify local/stale status rather than generic uncertainty; conflict must identify competing versions and the non-destructive comparison step.

## Localization gate
CD029 remains the production blocker. A valid resource transfer must exercise ARB/resource extraction and re-import/reconciliation, placeholders, plural/select, locale-backed date/time/duration formatting, long-string expansion, terminology propagation and fallback behavior. String-length simulation alone is not localization evidence.

## Accessibility semantics
Visible state title, status announcement and action label should express the same underlying state/action contract without requiring color references. Repeated announcements must be governed by actual transition behavior; static prose cannot establish screen-reader usability.
