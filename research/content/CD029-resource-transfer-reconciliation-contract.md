Classification: **PRODUCTION TRANSFER PRACTICE + EXECUTABLE CONTRACT**

## Purpose
Advance beyond synthetic release manifests toward an actual resource-package round trip without pretending that machine-valid resources equal linguistic quality.

## RELATED DOMAIN CHECK
I010 owns state/action/recovery truth. L015 owns rendered survival. W022 defines the browser capture bundle. C024 requires verbal state identity without hue. T022 receives literal and locale-formatted stress strings.

## Bounded transfer target
Use a Flutter-ARB-class package first because LogMate is Flutter-based, while keeping the semantic model format-neutral. Each resource must retain or reconcile:
- stable message ID;
- semantic revision;
- description/context;
- typed placeholders;
- literal operational identifiers vs localizable values;
- plural/select structure where applicable;
- risk tier / required QA class;
- source-locale realization.

## Round-trip assertions
`semantic inventory → ARB-class export → synthetic locale realization → import/reconciliation → semantic/release gates` must reject:
1. dropped message IDs;
2. stale semantic revisions;
3. placeholder name/type drift;
4. plural/select branch loss;
5. accidental localization of operational literals;
6. source-string edits treated as harmless when semantic revision changed;
7. locale resource present but required review/render/functional evidence absent;
8. fallback that violates the message risk policy.

## UX integration
Resource validity supports semantic continuity but does not prove wording comprehension. Critical certainty/recovery messages remain release blockers if localization or rendering drops the state distinction or safe action.
