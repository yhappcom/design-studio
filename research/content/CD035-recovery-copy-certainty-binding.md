# CD035 — Recovery copy certainty binding

Date: 2026-09-16
Evidence class: **TRANSFER VALIDATION / semantic contract refinement**

## RELATED DOMAIN CHECK
I016 supplies executed certainty evidence; W027/W028 supplies the runtime fixture; L020 and C029 will test whether the resulting states/actions remain reachable and visually distinguishable. Type T021 remains behind its repertoire/drawing gate and must not force semantic shortening.

## Validated distinction
The W028 adversarial pair proves that identical response-loss symptoms can hide different commit outcomes. Therefore user-facing copy must be selected from authoritative certainty, not from the generic network exception.

### Pre-reconciliation
- State title: **Outcome unknown**
- Explanation: the response was interrupted, so completion is not yet confirmed.
- Primary safe action: **Check outcome**
- Forbidden implication: “Save failed”, “Try again” or equivalent unless the operation contract makes retry safe.

### Reconciled confirmed
- State title: **Completed**
- Explanation: the latest record confirms the operation completed.
- Next action may return to the normal workflow; retry is removed.

### Reconciled not-found in this fixture
- State title: **Not found after check**
- Explanation must avoid pretending that this controlled fixture is a universal production guarantee. Product copy may offer retry only when backend semantics establish that absence means no commit or the operation is safely idempotent.

### Known rejection
- State title: **Couldn’t complete** (or product-specific reason when authoritative and useful)
- The message may state failure because the response itself carries authoritative rejection semantics in this fixture.

## Localization/resource consequence
The four states require distinct semantic message IDs even if a locale later chooses similar surface wording. They must not be collapsed to save string count or layout space. Placeholder data should include stable record/operation identity where users need to verify the affected object.

## Evidence boundary
This is expert semantic transfer from a controlled backend validation, not human comprehension or linguistic-review evidence. Actual ARB/gen-l10n/TMS round trip and locale review remain OPEN.
