T021 requires mature fallback metrics; C033 supplies degradation rungs; L024/I020 define resumption priority/action safety; CD038 supplies semantic invariant vectors. UX remains cross-cutting, not a new owner.

## Why W033
W032 made Stage-3 execution portable. The next gap is product-likeness: route/history and network recovery must preserve a durable task reference across reload/later return rather than only exercise a transient demo panel.

## Fixture contract
The fixture must expose stable object ID, operation ID, route/deep-link, persisted authoritative outcome, reconciliation endpoint, history/detail route and conflict variant. Required scenarios: fresh success; known rejection; drop-before; drop-after; reload while unknown; navigate away/back; later return; history unavailable; conflict.

Each run records engine/version, OS, viewport + visualViewport, zoom method/value, forced-colors state, locale, route, object/operation IDs, immediate certainty, reconciled certainty, enabled actions, focus target/rect, authored overlay rect, scroll dimensions and capture ID.

## Accessibility/runtime baseline
Use WCAG 2.2 as the current W3C baseline. Focus Not Obscured (Minimum) is evaluated independently from contrast/state differentiation. Forced-colors is an executed browser mode, not a static CSS inference.

## Performance evidence boundary
Functional fixture timings are diagnostics only. No field LCP/INP/CLS claim is made without actual field/RUM population evidence and context; lab values remain lab evidence.

## Current blocker
The current connector/container context has not produced an executed multi-engine browser artifact. W033 therefore defines the next product-like executable target but remains OPEN. Do not synthesize browser, Safari, AT, physical-device or human UX results.
