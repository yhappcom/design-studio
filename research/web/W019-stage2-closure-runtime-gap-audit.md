## Accessibility standard correction
WCAG 2.2 is the current W3C-recommended WCAG baseline. Target Size (Minimum) 2.5.8 is AA at 24×24 CSS px with specified exceptions. Focus Not Obscured (Minimum) 2.4.11 is AA. Focus Appearance is 2.4.13 at AAA in the published WCAG 2.2 material; therefore do not incorrectly label it AA.
