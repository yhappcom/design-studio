Preserve per scenario: screenshot(s), accessibility/semantics snapshot, focus/navigation trace, console/runtime log, network trace where relevant, overflow/layout diagnostics, task result and peer-oracle classifications. Generate a manifest linking every artifact to Phase A identity.
