# C113 — Stage 3 closure evidence compression

Date: 2026-09-20
Purpose: CONTRADICTION REVIEW / systems-practice closure planning.

## Finding
Color now has broad semantic-state theory. The bottleneck is transfer evidence, not another palette exercise. Closure work must prove that state hierarchy survives real LogMate surfaces and rendering modes.

## Required state matrix
Validate focus, current location, selection, invalid/ambiguous, warning, loading/pending, offline/degraded, persistence failure, evidenced success, recovery/Undo and stale/superseded states without collapsing them into one accent channel.

## Transfer matrix
Use materially different surfaces: Home/navigation, dense ledger/search results, form/error/recovery and one persistence/offline flow. Test light/night, forced-colors and enlarged/text-spacing layouts. Decorative brand chroma must yield before functional salience.

## Rejection rules
- success paint before persistence evidence: FAIL
- current destination indistinguishable from focus: FAIL
- zero-result treated as error solely by color: FAIL
- quiet/premium treatment reducing consequence-bearing salience: FAIL
- forced-colors removing the only state cue: FAIL

## Cross-domain handoff
Interaction owns state authority; Content owns state wording; Layout owns occlusion/placement; Web owns actual rendering/provenance; Type fallback must not remove non-color cues.

## Evidence boundary
No Stage 3 PASS, production palette approval, forced-colors transfer, physical-device, AT or human salience evidence is claimed.
