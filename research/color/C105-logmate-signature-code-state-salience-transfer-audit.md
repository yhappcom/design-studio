# C105 — LogMate Signature-Code State-Salience Transfer Audit

Status: **STAGE 3 PRACTICE / CONTRADICTION REVIEW — no palette or gate promotion**

## PURPOSE
Test whether SC-A–SC-D can remain recognizable without converting brand expression into semantic-color dependence.

## RELATED DOMAIN CHECK
Type T074/T073 constraints, I091/L095 semantic geometry, W104 runtime ladder, CD110 content truth, and the completed Signature Code Study were checked.

## CONTRADICTION REVIEW
- **SC-A Calibrated Axis:** alignment must remain perceptible when authored color disappears. Color may reinforce grouping, never create the only axis.
- **SC-B Operational Dual Voice:** role distinction must survive monochrome/forced-colors; chroma is optional support.
- **SC-C Quiet Functional Boundary:** highest risk. 'Quiet' cannot erase focus, selection, invalid, ambiguity or recovery ownership. Remove decorative competition before functional salience.
- **SC-D Measured Transition/Recovery:** state change cannot depend on transient color or motion. Resting result and recovery availability require persistent non-color semantics where needed.

## SYSTEMS PRACTICE CONTRACT
For each new concept, inspect at least these states on Home, ledger, Activity, Add Flight and Customize/import where applicable:
rest; hover where applicable; focus; selected; editing; invalid; ambiguous; pending; committed; recovery available; recovery failed/expired; disabled/unavailable.

Run the same semantic-state matrix under:
- light;
- night/dark realization;
- forced-colors / authored-color loss;
- stale-state cleanup after route, Undo, Reset and import transitions.

Failure conditions:
- accent color carries both brand identity and mutually different semantic states;
- selected/focus/invalid become indistinguishable after authored-color loss;
- success paint persists after state invalidation;
- quiet surfaces reduce target/focus ownership below functional clarity;
- a palette is declared production-ready from static contrast calculations alone.

## SYNTHESIS
LogMate's strongest color contribution to authorship is likely **disciplined salience allocation**, not a signature hue. This is compatible with SC-C only if semantic hierarchy survives color removal.

## OPEN
No production palette, rendered cross-surface evidence, independent-engine/device evidence, calibrated-display/glare/night observer evidence or human state-recognition PASS exists.

## HANDOFFS TO OTHER SPECIALISTS
- Layout/Interaction: boundary quietness must be evaluated together with focus/recovery geometry.
- Web: capture computed/forced-color outcomes, not screenshots alone.
- Content: semantic state names remain authoritative when visual color is transformed.
