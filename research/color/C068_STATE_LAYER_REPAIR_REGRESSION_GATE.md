# C068 — State-Layer Repair Regression Gate

Status: PRACTICE / TRANSFER VALIDATION
Date: 2026-09-18

## Purpose
Verify that Material/layer repair restores visible interaction state without collapsing financial semantics into color alone.

## Required axes
Evaluate independently: brand, financial polarity, certainty/finality, availability/integrity, selection, pressed/focus/hover where applicable. A token may be correct while the rendered state is absent; TOKEN_PASS / RENDER_FAIL is a failure.

## Contradiction fixtures
- positive income + negative total return
- zero vs unavailable
- estimated vs final
- partial vs complete
- gross vs net / tax-adjusted
- locale-specific polarity conventions

Every state must remain recoverable without hue alone through sign, text, iconography, structure, or other redundant cue.

## Layer acceptance
For interactive rows, verify that decoration does not obscure Material ink/state feedback. Repair must preserve semantic background ownership and visible pressed/selected feedback rather than simply removing splash/state rendering.

## Evidence
Automated rendering can establish presence/absence and contrast measurements; calibrated-display perception and human interpretation remain OPEN.

## Related-domain check
Layout/Interaction owns geometry and action behavior; Content owns labels and state meaning; Web owns runtime provenance. WCAG 2.2 remains the accessibility baseline for web transfer.
