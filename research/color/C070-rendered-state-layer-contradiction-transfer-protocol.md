# C070 — Rendered state-layer contradiction transfer protocol

## Purpose
Advance Color beyond token inspection by proving that semantic states survive the actual paint/layer hierarchy after the MintTap Material repair.

## Stage
Stage 3 PRACTICE / NOT PASSED. This is TRANSFER VALIDATION, not a new token exercise.

## SOURCE model
State meaning is decomposed into independent axes:
- brand identity;
- financial polarity;
- certainty/finality;
- availability/integrity;
- interaction state: selected, pressed, focus, disabled.

The previous Material assertion means a correct token value is insufficient evidence when an intervening painted surface can suppress Ink/state feedback.

## PRACTICE matrix
Use one repaired build and deliberately combine contradictory states:

| Fixture | Required semantic recovery |
|---|---|
| high income + negative total return | income and total-return polarity remain independently legible |
| zero + unavailable | zero is not mistaken for missing data |
| estimated + positive | certainty does not collapse into polarity |
| final + negative | finality remains distinct from loss |
| partial + positive | completeness remains distinct from gain |
| gross + net | tax basis remains explicit |
| selected + negative | selection does not overwrite financial polarity |
| focused + unavailable | focus remains visible without converting unavailable to active |

For each fixture capture TOKEN → PAINT OWNER → VISIBLE SURFACE → NON-COLOR CUE → ACCESSIBLE MEANING.

## CRITIQUE classes
- TOKEN_FAIL
- PAINT_OWNER_FAIL
- OCCLUSION_FAIL
- CONTRADICTION_COLLAPSE
- NON_COLOR_CUE_FAIL
- ACCESSIBLE_MEANING_DRIFT

`TOKEN_PASS / RENDER_FAIL` is an explicit failure, not partial success.

## Reproducible validation
A state passes only when its visible surface is actually rendered in idle/focus/pressed/selected states and the meaning remains recoverable without hue alone. Screenshot evidence must be paired with state identity and interaction step; a static palette image is insufficient.

## Product-transfer boundary
Display calibration, color-vision user observation and representative-human interpretation remain OPEN. Automated contrast/state checks cannot close those evidence classes.

## RELATED DOMAIN CHECK
Layout supplies the surface/layer structure; Interaction supplies state transitions; Content supplies labels/qualifiers; Type must preserve legibility; Web supplies browser/runtime evidence provenance.
