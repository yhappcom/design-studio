# C120 — Cross-Concept State Injection Matrix

## PURPOSE
Turn C119 semantic-rank findings into a shared Candidate 05/07 state-injection fixture while preserving each palette's atmosphere.

## RELATED DOMAIN CHECK
Type T089, Interaction I106, Layout L110, Web W119 and Content CD125 were checked. State authority comes from Interaction; wording from Content; Color owns visual encoding and redundancy.

## PRACTICE / CRITIQUE
Inject the same authorized states into both coded candidates: focus, current location, selection, invalid/error, pending, offline/degraded, recovery available and evidenced success. Repeat after max text scaling/fallback/reflow.

For every state record: semantic ID, owner object, color token/appearance, non-color cue, adjacency after reflow, theme/accessibility mode and whether another simultaneous state remains distinguishable.

Failure conditions:
- brand accent substitutes for several materially different states;
- success appears before authoritative evidence;
- error/offline/pending collapse into one warning treatment;
- a state becomes color-only;
- Candidate 05/07 palettes are normalized merely to simplify implementation;
- native high-contrast evidence is treated as equivalent to Flutter Web forced-colors evidence.

## EVIDENCE BOUNDARY
This matrix is pre-runtime practice. No Stage 3 PASS, accessibility-mode runtime PASS, calibrated-display, glare/night, observer or human evidence is claimed.

## HANDOFFS TO OTHER SPECIALISTS
Web receives the capture schema; Layout must preserve cue ownership under recomposition; Content must verbalize materially distinct states; Interaction supplies authoritative state transitions.
