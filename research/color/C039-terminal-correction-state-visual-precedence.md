## Principle
A terminal conflict/intervention-required state outranks historical optimistic success and intermediate compensation-success styling. Visual emphasis must follow current authoritative consequence and safe action, not the most recent locally successful animation or brand-primary treatment.

## Failure injection matrix
For each terminal state test: normal light/dark; remove authored hue; remove icon/shape; forced-colors; keyboard focus on safe action; selected historical operation; stale success region still mounted; overlay/sticky layer active.

Reject when terminal meaning depends on authored hue alone, stale success remains the dominant state cue, focus/selection is mistaken for authority, disabled/unsafe mutation retains primary-action appearance, or forced-colors erases the distinction without text/structure survival.

## Required evidence
Shared runtime ID with semantic state, computed foreground/background/border/outline, focus indicator geometry, forced-colors mode, visible non-color state label, and L030 dominance/occlusion geometry.

Contrast conformance, semantic distinguishability, focus visibility and focus obscuration remain separate verdicts.
