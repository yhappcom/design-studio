# LogMate Home White-Canvas Draft 01 — Specialist Review

Date: 2026-09-20
Status: PRE-RENDER REVIEW / STATIC CONCEPT ONLY
Upstream: current LogMate MASTER/specs, visual-identity restart, Design Studio synthesis chain, current specialist status through T083/C114/I101+L105/W114/CD120.

## Draft objective

Produce the first Home visual concept after the white-canvas restart without reusing Round-1 A/B/C geometry and without inventing product semantics.

Target impression:
- clean;
- precise;
- quiet;
- premium;
- professional.

Premium must come from execution discipline, not luxury decoration.

## Asset lock

Use current product assets/identity evidence:
- canonical text wordmark behavior from LogMateWordmark: LOG + small gap + MATE, with MATE receiving the brand accent;
- current implementation brand asset/token: #00A693, used sparingly;
- current light canvas evidence: #FFFAF8 / dark primary text #171715;
- actual Home mock data and canonical product labels;
- bundled airport/aircraft data remain product assets but are not visually fabricated in this static Home concept.

Do not invent:
- greeting;
- pilot rank/name;
- slogan/tagline;
- performance chart;
- growth percentage;
- weather;
- sync state;
- airline branding.

## Type specialist

Required:
- proportional UI voice for labels/actions/section titles;
- operational mono role for repeated Flight identifiers and other confirmed comparison data;
- Flight keeps carrier + number/suffix zoning;
- arbitrary-language Remark remains fallback-safe proportional/free-text role;
- no geometry may depend on unfinished custom type.

Draft implication:
- stronger contrast comes from role and weight, not a decorative typeface.
- no global monospace.

## Color specialist

Required:
- brand color is not semantic authority;
- neutral structure first;
- functional focus/selection/error/recovery outrank brand accent;
- color is never the only state cue.

Draft implication:
- warm neutral canvas dominates;
- brand green is scarce;
- no large colored hero card;
- no gradient/metal/glass luxury shortcut.

## Layout / spatial specialist

Required:
- stable semantic axes;
- whitespace is structural;
- dense information may remain calm;
- low chrome is acceptable only where grouping remains clear;
- Home is not forced into card/dashboard grammar;
- no bottom navigation while product IA is still redundant with Home.

Draft implication:
- one continuous working surface;
- section changes through spacing, baseline, hierarchy and low-contrast rules;
- Recent Flights is the strongest operational-axis demonstration.

## Interaction specialist

Required:
- do not invent SEARCH-001 behavior;
- primary actions remain explicit and equal in semantic hierarchy;
- state/consequence/recovery truth outranks visual signature.

Draft implication:
- Search is only an input shell.
- Add Flight and View Logbook are two restrained direct actions, not FAB/hero-card hierarchy.
- no invented save/sync badges.

## Content specialist

Required:
- product-authored UI English-only;
- current Home concept uses 7 days / 28 days / 90 days / Custom;
- professional terminology remains intact;
- no unapproved brand voice claims.

Draft implication:
- use canonical labels only.
- no Good evening, Captain, no tagline, no invented explanatory copy.

## Web/runtime specialist

Boundary:
- this concept is static visual evidence only;
- no runtime/browser/native/200%/forced-colors/device PASS is implied.

## Concept-level composition approved for rendering

Reference mobile viewport: 390 × 844 logical class.

Order:
1. compact header with centered LogMate wordmark + Settings;
2. equal primary actions on one quiet action rail;
3. Search logbook shell;
4. Current Period with month context and paired Block Time values;
5. Recent Flights as open, ledger-like calibrated rows;
6. Activity with 7/28/90/Custom selector and three stats;
7. Totals with three aligned summary values;
8. quiet safe-area ending.

Visual grammar:
- no repeated cards;
- no large rounded containers;
- no bottom navigation;
- no chart;
- no decorative aviation motifs;
- no hardware-device marketing frame;
- hairlines only where they perform structure;
- generous but not empty vertical rhythm.
